# Números Primos em C

## Sobre o projeto

Este projeto consiste em um programa desenvolvido na linguagem C que recebe um número inteiro informado pelo usuário e apresenta todos os números primos de 1 até o valor digitado.

O objetivo é praticar conceitos fundamentais de programação, como estruturas de repetição, estruturas condicionais e lógica computacional.

## Funcionalidades

- Recebe um número inteiro como entrada.
- Identifica os números primos no intervalo de 1 até o valor informado.
- Exibe os números primos encontrados.

## Tecnologias utilizadas

- Linguagem C
- GCC (compilador C)

## Organização dos arquivos

O código-fonte do projeto está armazenado na pasta `codigos c` deste repositório.

## Como compilar e executar

É necessário ter um compilador C, como o GCC, instalado no computador.

1. Clone ou baixe este repositório.
2. Abra o terminal na pasta principal do repositório.
3. Compile o programa, substituindo `SEU_ARQUIVO.c` pelo nome real do arquivo C:

```bash
gcc "codigos c/SEU_ARQUIVO.c" -o numeros_primos
```

4. Execute o programa.

No Linux ou macOS:

```bash
./numeros_primos
```

No Windows, utilizando GCC:

```bash
numeros_primos.exe
```
