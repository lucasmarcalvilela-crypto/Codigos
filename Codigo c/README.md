# Números Primos em C

## Sobre o projeto

Este projeto consiste em um programa desenvolvido na linguagem C que recebe um número inteiro informado pelo usuário e apresenta todos os números primos de 1 até o valor digitado.

O objetivo é praticar conceitos fundamentais de programação, como estruturas de repetição, condicionais, operações matemáticas e lógica computacional.

## Funcionalidades

- Recebe um número inteiro como entrada.
- Identifica os números primos no intervalo de 1 até o valor informado.
- Exibe os números primos encontrados.

## Tecnologias utilizadas

- Linguagem C
- Compilador C, como GCC

## Como executar

É necessário ter um compilador C instalado, como o GCC.

1. Clone ou baixe este repositório.
2. Abra um terminal na pasta do projeto.
3. Compile o arquivo-fonte, substituindo `primos.c` pelo nome real do arquivo, caso seja diferente:

gcc numeros_primos.c -o numeros_primos

4. Execute o programa.

No Linux ou macOS:

./numeros_primos

No Windows, utilizando GCC:

numeros_primos.exe
